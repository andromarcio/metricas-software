# Método COSMIC para Medição de Tamanho Funcional — Versão 3.0.1 · Manual de Medição

Conversão em Markdown do **COSMIC Method v3.0.1 — Measurement Manual** (tradução em
português — *Manual de Medição*), a partir do arquivo
[`COSMIC_Method_v3.0.1_Measurement_Manual_Portuguese.pdf`](../COSMIC_Method_v3.0.1_Measurement_Manual_Portuguese.pdf)
(81 páginas).

- **Subtítulo:** Guia de Implementação COSMIC para a ISO/IEC 19761: 2003
- **Publicação:** The Common Software Measurement International Consortium (COSMIC), Maio de 2009
- **Autores (Equipe Principal COSMIC v2.01):** Alain Abran, Jean-Marc Desharnais,
  Serge Oligny, Denis St-Pierre, Charles Symons

> Esta conversão preserva a estrutura, as tabelas e as figuras do manual original.
> Cada tabela foi convertida para Markdown; cada figura (diagramas de contexto, modelo
> genérico, movimentações de dados E/X/R/W, etc.) foi extraída como imagem e
> referenciada no seu local. As caixas de **PRINCÍPIOS** e **REGRAS** do método foram
> reproduzidas como blocos de citação. Em caso de divergência, prevalece o PDF original.
